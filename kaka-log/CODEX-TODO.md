# KAKA PC v1.3 개발 인수인계

현재 코드는 v1.2.0 + Electron 복구 수정 패치입니다. 아래 항목은 미구현 개발 계획이며, 버전 번호는 완료 및 검증 후 변경합니다.

- 달력 높이 축소 (필요한 주만 표시), 연도 잘림 해결, 연도·월 중앙 정렬, 현재 연도/월 이후 제한 유지.
- 정비 항목 6개 분류: 엔진 · 구동계, 브레이크, 타이어 · 하체, 냉각 · 공조, 전기 · 소모품, 차량 관리 · 기타. 사용자 추가 소모품 별도 분류 및 중복 방지. 검색은 띄어쓰기 무시.
- 엔진 오일, 미션 오일, 브레이크 패드 등 띄어쓰기 통일. 기존 명칭/ID 및 사용자 입력 보존, 소모품 연동과 기존 기록 호환 유지.
- 날짜 순서와 주행거리 불일치 시 경고하되 확인 후 저장 허용.
- 비용 통계: 누적 정비 비용(지금까지 차에 꼴아박은 돈), 올해 비용, 월평균 비용(올해 경과한 월 기준), 항목별 지출 순위, 기존 월별 통계 유지.
- 화이트 테마 대비 개선: 기본 글자 #222222, 보조 #55555b, 정상 #28794d, 임박 #996000, 필요 #bd3535, 기록 없음 #626269. 입력 및 버튼, 달력, 차량 구분 색상 확인. 그래파이트 디자인 유지.
- 한국어/영어 즉시 전환, 설정 기억, 모든 UI/오류/기본 정비 항목 번역. 저장 ID와 표시 명칭 분리. 사용자 차량명·메모·추가 소모품은 원문 유지. 원화 및 km 유지.
- Electron 자동 복구 최신 패치 포함 상태에서 Windows 실제 실행 검사. 다운로드 검증 및 기존 데이터 보존.

기존 SQLite/JSON 백업, %APPDATA%/KAKA 저장 경로, 내부 식별자, 원본 아이콘, 경기천년제목 폰트 설정, 차량 구분 색상, 전기차 기본 소모품, 정비 기록 연동, 오프라인 사용 유지. 모바일 제외. 기존 node_modules 삭제 금지. Windows 실행 테스트 미완료.
